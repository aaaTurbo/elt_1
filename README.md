# Download Speed Benchmark CLI

Консольная утилита на Node.js для последовательного замера скорости скачивания файла по HTTP/HTTPS.

## Реализация
- **Без внешних зависимостей** — используются только встроенные модули Node.js (`fetch`, `node:perf_hooks`, `node:test`).
- **Защита от кэширования** — к каждому запросу добавляется уникальный query-параметр `_nocache` и заголовки `Cache-Control: no-cache`, чтобы замерять реальную скорость сети, а не локальный/CDN-кэш.
- **Таймаут запросов** — защита от зависания при обрыве связи (15 секунд на запрос).

## Требования
- **Node.js** версии `20.0.0` или выше.

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-проекта>
   ```

2. Установите зависимости, запустите скрипт, передав URL файла в качестве аргумента. 
Например:
   ```bash
   npm install
   npm start -- "https://speedtest.selectel.ru/10MB?pk_vid=6cf696f04f02e5d71794529730f52328"
   ```

## Единицы измерения
- **Объём данных:** Мегабиты (`Мб`), где `1 Мб = 8 388 608 бит`.
- **Время запроса:** Миллисекунды (`мс`).
- **Скорость скачивания:** Мегабиты в секунду (`Мб/с`).
